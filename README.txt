Shubh Vivah - Deepika & Vikas Wedding Invitation Web App
=========================================================

HOW TO HOST FOR FREE IN UNDER 2 MINUTES:

Option 1: Netlify Drop (Fastest & Easiest - No Coding)
1. Go to https://app.netlify.com/drop
2. Drag and drop this folder (or unzip and drop the folder containing index.html).
3. Your live link is created instantly! (e.g., https://deepika-vikas-wedding.netlify.app)
4. You can customize the site name in "Site Configuration" -> "Change site name".

Option 2: GitHub Pages (Permanent & 100% Free)
1. Create a free account on https://github.com and create a new public repository (e.g., "deepika-vikas-wedding").
2. Upload "index.html".
3. Go to Repository Settings -> Pages -> Source: select "main" branch and save.
4. Your live link will be: https://<your-username>.github.io/deepika-vikas-wedding/

Option 3: Tiiny Host (Single File Drag & Drop)
1. Go to https://tiiny.host
2. Upload "index.html", choose a link name (e.g. deepika-vikas), and click Launch!
