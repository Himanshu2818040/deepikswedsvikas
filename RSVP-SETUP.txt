SAVING RSVPs TO GOOGLE SHEETS (free, ~5 minutes)
================================================

1. Create a new Google Sheet. Name it "Wedding RSVPs".
2. Menu: Extensions > Apps Script. Delete the sample code and paste this:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Time', 'Name', 'City', 'Relation', 'Message', 'Invited as', 'Side']);
  }
  var p = e.parameter;
  sheet.appendRow([new Date(), p.name, p.contact, p.attendance, p.message, p.invitedAs, p.side]);
  return ContentService.createTextOutput('ok');
}

3. Click Deploy > New deployment > gear icon > Web app.
     Execute as:      Me
     Who has access:  Anyone
   Click Deploy and authorize when asked (Advanced > Go to project).
4. Copy the "Web app URL" (ends with /exec).
5. In index.html find:   const RSVP_ENDPOINT = '';
   and paste the URL between the quotes.
6. Re-upload index.html to your host and submit a test RSVP. A row should appear in the sheet.

Already have the sheet running? Add a "Side" header in cell G1 and update the two lines
above in the script, then Deploy > Manage deployments > Edit > New version. Rows from the
bride's page say Bride, rows from the groom's page say Groom (older rows stay blank).

If you edit the script later, use Deploy > Manage deployments > Edit > New version.
